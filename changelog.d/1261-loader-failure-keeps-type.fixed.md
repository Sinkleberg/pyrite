- A file whose type's loader raises (a value that will not convert, a missing field, a plugin validator) is reported as malformed by `pyrite index sync` and `pyrite index health`, naming the file and the loader's message. It used to be indexed silently as an `event`, so a `backlog_item` with a bad `rank` disappeared from `pyrite sw backlog`. `pyrite get` still returns such a file, as the type it declares, with a `load_problems` list naming each field the loader refused; `pyrite update` that fixes the field repairs the file, and an update of another field succeeds with a warning. A file whose frontmatter is empty (`---` then `---`) loads as a note, like any file with no `type:`. (#1261)
